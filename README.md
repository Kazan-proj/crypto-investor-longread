# Лонгрид о пути инвестора на регулируемом крипторынке

Статический сайт для лабораторной работы по интернет-технологиям.

## Локальный просмотр

Откройте `index.html` в браузере или запустите в этой папке:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000/.

## Публикация на GitHub Pages

Все файлы сайта находятся в корне репозитория. GitHub Pages публикует
ветку `main` из `/(root)`. Адрес сайта:
https://kazan-proj.github.io/crypto-investor-longread/.

## Устройство

- `index.html` — текст, источники и разметка.
- `styles.css` — оформление и адаптация к экранам.
- `app.js` — интерактивный маршрут, оглавление и индикатор чтения.
- `*.svg`, `*.mp4`, `*.vtt` — оригинальные иллюстрации, видео и субтитры.

Все юридические факты имеют прямые ссылки на официальные источники.
Дата проверки источников указана на странице. Схема маршрута является
учебной моделью, а не описанием конкретного сервиса.
